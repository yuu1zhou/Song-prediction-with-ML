# Million Song Dataset -- Song Popularity Prediction 

This is a personal machine learning practice project focused on the music industry. We compared both classic and widely used machine learning algorithms for predicting song popularity. Feature engineering techniques such as Bag-of-Words (BoW) and variable selection methods are applied for model performance improvement.
